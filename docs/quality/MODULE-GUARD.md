# Cithadell Module Guard
Scope: Le Chantilly only. Baseline 54ac526dbef20a8cdc20d0fcb0e54edf00b83766. Backup branch recovery/v0.15.0-dev-20261124 is a recovery pointer, not immutable storage or a DB backup.
## Enforcement
Manifest records 11 functional groups and all 128 tracked baseline paths, including historical/pending work. Guard reads Git objects, never imports proposed application code. It compares all tracked base files with candidate, blocks deletion/rename/symlink, edits to prior migrations, controls/tests/CI, archive overwrite, existing script changes, API operation drift, missing capability markers and suspicious new SQL. It allows additive files and ordinary modifications to module implementations. SQL checks are conservative heuristics, not a parser; a flagged migration must be independently reviewed.
Run from committed checkout: node scripts/module-guard.mjs BASE_SHA HEAD_SHA. npm run guard:inventory is a structural check of HEAD, not a diff or a check of uncommitted work. npm run verify additionally runs existing Node tests. Candidate workflow verifies merged PR; trusted pull_request_target workflow uses base code only, read-only permissions, public Git refs, no checkout/execution of candidate, no secrets. Trusted workflow activates only once merged into main. Keep branch up to date; stale base fails. Do not use pull_request_target for candidate build/tests.
