# Catalog foundation — development only
Applied to dedicated lechantilly-dev, not linked to production. The prior proposed 001 migration is superseded and must not be applied. Immutable normalized revisions contain categories, products, many-to-many categories, variants, collections and production families independent of commercial labels. Stable UUID identity per business and revision; draft saves require expected revision under a business row lock; publication requires expected draft and publication numbers. Only currently edited or previously published revision can be published/restored. Public preview projection excludes family identifiers and draft prices, never confirms availability or checkout. Explicit owner membership and AAL2 checked in private security-definer functions; public RPC wrappers are invoker, no direct table writes. No real identity provisioned. Recipes/finance/order modules and auth sessions remain future work; do not insert real data.
## Applied hardening
Migrations 003–005 implement a non-login executor with narrow DML grants and RLS policies; managed auth identity is resolved in a narrowly scoped private helper. Strict JSON type validation rejects coercions. Recipe drafts are business-owned, immutable revisions with compare-and-swap and archival. Regression SQL is at database/tests/development_catalog_regression.sql, transaction rollback, simulated claims under actual authenticated/anon database roles. Runtime Auth token delivery/enrollment/recovery and separate Studio UI have not been enabled. The development snapshot adapter has no historical fallback and is read-only; live API remains on the historical preview. No public signup or identity settings changed; require verification before onboarding.
## Activation controls
Use LC_CATALOG_MODE=development-db, LC_SUPABASE_URL, LC_SUPABASE_PUBLISHABLE_KEY, LC_BUSINESS_ID and LC_DEV_FRONTEND_ORIGIN only in local development or Vercel Preview. Never configure production. No service key. Missing publication returns 503; quote/basket returns 409. Publishing in database does not launch commercial sale.
