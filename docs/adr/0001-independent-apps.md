# ADR 0001 — Frontend y backend independientes
Estado: aceptada (v0.7).
Contexto: tienda artesanal; separar interfaz de autoridad de negocio sin alterar la estética ni crear otros negocios. Monorepo y despliegues separados. El backend verifica productos, precios y cantidades; el frontend únicamente presenta, solicita validación HTTP y prepara mensajes. El catálogo histórico permanece no comercial. Studio no es administración autenticada; sus borradores no se publican. La API recibe los textos de consulta al solicitar validación, sin almacenamiento aplicativo; evitar datos sensibles. CORS restringe navegadores, no autentica clientes. No existen rutas administrativas, pagos ni escritura persistente. Contrato HTTP OpenAPI v1. El uso de Node.js y el frontend estático es una etapa transitoria de bajo riesgo, no la migración completa a Next/Nest. PostgreSQL y Prisma requieren proveedor aprobado y esquema/migraciones revisados; no simular persistencia. Antes de lanzamiento: auth/RBAC, límites de consumo, protección antiabuso, E2E, accesibilidad, monitoreo, comercialización permitida, política de privacidad y autorización de propietaria.
