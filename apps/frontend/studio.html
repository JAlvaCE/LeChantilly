Planificación artesanal

Le Chantilly Studio.

Organiza borradores de catálogo, estima costos y planifica capacidad en este navegador. Nada se publica ni almacena automáticamente. La API recibe los importes y duraciones para calcular resultados; los nombres de actividades permanecen locales. Usa exclusivamente valores de prueba hasta disponer de un Studio autenticado. No introduzcas datos de clientes, pedidos reales ni información confidencial; los borradores se mantienen en memoria y se pierden al recargar salvo que exportes los archivos.

Editor de catálogo
